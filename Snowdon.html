BIM QA Dashboard
SNOWDON TOWERS

An end-to-end BIM data workflow that extracts information from a Revit model using Dynamo, cleans and transforms the datasets with Power Query, and presents model information, asset metadata, and compliance indicators through Power BI.

BIM models contain the information.
The challenge is making it reviewable.

A Revit model can contain thousands of elements, hundreds of parameters, project information, and warnings. But reviewing that information can mean moving between views, schedules, filters, and individual elements.

The challenge is not simply accessing BIM data. It is turning that data into information that can be reviewed, filtered, investigated, and communicated.

A sample project
used as a real BIM data environment.

This workflow is demonstrated using Snowdon Towers, Autodesk's sample architectural project for Revit. The project represents a mixed-use development in Brownsville, Pennsylvania, with residential, commercial, and retail spaces.

Rather than presenting a hypothetical dataset, the dashboard is built around the actual information contained within the sample model—its elements, categories, families, types, parameters, and Revit warnings.

This makes Snowdon Towers the test environment for exploring how BIM information can be extracted from a model and transformed into a reviewable QA/QC environment.

Four questions
every model review starts with.

This creates a simple problem. The dashboard is built to answer each of these questions in one place.

What is actually in the model?

Explore model elements through categories, families, types, levels, and summary metrics.

Which elements have incomplete information?

View element-level parameters in a single matrix to identify incomplete or missing information.

Where are the warnings?

Connect Revit warnings to affected elements and organize them for investigation.

Which elements are affected?

The dashboard combines analytical data with an interactive 3D model through Speckle, connecting each finding back to its physical context within the BIM model.
